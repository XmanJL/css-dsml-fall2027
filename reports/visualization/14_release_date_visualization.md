# Release Date and Popularity Visualizations

## Overview

This analysis explores how movie release patterns and target log popularity vary across years, decades, and months. The analysis uses the engineered popularity features from `09_popularity_features.csv`.

## 1. Movie Count by Release Decade

The number of movies in the dataset increases substantially across more recent decades, particularly after 1980. The 2000s and 2010s contain a large portion of the movies represented in the dataset.

**Main Insight:** The dataset contains considerably more movies from recent decades than from early cinema.

## 2. Average Target Log Popularity by Release Decade

Average `target_log_popularity` generally increases across release decades. Early decades have lower average popularity, while more recent decades tend to have higher values.

**Main Insight:** More recently released movies generally have higher average target log popularity in this dataset.

## 3. Movie Counts by Release Decade and Month

The heatmap compares movie counts across both release decade and release month. Movie releases become much more concentrated in recent decades, while release volume also varies across months.

**Main Insight:** Release activity varies by both decade and month, with the largest concentrations occurring in more recent decades.

## 4. Average Target Log Popularity by Release Year

The yearly visualization provides a more detailed view of the popularity trend. Although individual years fluctuate, average target log popularity generally increases over time.

**Main Insight:** The year-level results support the broader decade-level trend toward higher popularity among more recently released movies.

## 5. Average Target Log Popularity by Release Month

Average target log popularity is relatively consistent across most months. July has the highest average value at approximately 1.11, followed by December at approximately 1.07. January has the lowest average at approximately 0.74.

**Main Insight:** Release month shows some relationship with popularity, with July and December having the highest averages and January having the lowest.

## Key Takeaways

- Movie release volume increases substantially in more recent decades.
- Average target log popularity generally increases with more recent release years and decades.
- The yearly results show fluctuations but maintain the overall upward trend.
- Popularity is fairly consistent across most release months, with July highest and January lowest.
- Release volume varies across both decades and months.
