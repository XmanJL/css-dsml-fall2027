# CSS DSML Project — Fall 2027

A collaborative data science and machine learning project organized by CSS for Fall 2027.

## Team

- Supervisors: Jasper Liu, Liam Buckman
- Developers:  Hector Hernandez, Timothy Cortez, Kevin Phon, Anden Beers, Sarah Liu, Katia Choi, MD Arif Arman, Aaron Strong, Jessica Gonzalez, Grecia Mendoza

## Dataset

We will use [The MovieLens Dataset on Kaggle](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset/).

## Repository Structure

```text
css-dsml-fall2027/
├── data/
│   ├── raw/
│   ├── processed/
│   └── features/
├── notebooks/
│   ├── preprocessing/
│   ├── feature_engineering/
│   ├── visualization/
│   └── modeling/
├── reports/
│   ├── preprocessing/
│   ├── feature_engineering/
│   ├── visualization/
│   └── modeling/
├── models/
├── requirements.txt
├── .gitignore
└── README.md
```

The `data/` and `models/` directories are ignored by Git. They contain large metadata about the MovieLens dataset and model parameters. Create them locally if they do not already exist.
